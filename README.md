# Tatneft - тестовое задание

SPA-приложение для визуализации данных с возможностью ввода параметров вручную и через CSV-файл.


## Стек технологий

- **React 19** + **Vite**
- **TypeScript** - строгая типизация (`strict: true`)
- **Styled Components** - стилизация компонентов
- **Zustand** - глобальное управление состоянием
- **React Hook Form** - управление формой и валидация
- **ApexCharts** - визуализация данных
- **React Toastify** - уведомления об ошибках
- **ESLint** + **Prettier** - линтинг и форматирование

## Архитектура

Проект построен по методологии **Feature-Sliced Design (FSD)**:

```
src/
├── app/        # инициализация, роутинг, глобальные стили, сторы
├── pages/      # страницы приложения
├── features/   # пользовательские сценарии
│   ├── data-entry/     # форма ввода параметров
│   ├── chart/          # график и стор данных
│   └── import-csv/     # импорт данных из CSV
├── shared/     # переиспользуемые компоненты и утилиты
│   ├── ui/             # Input, Button
│   ├── assets/         # иконки SVG
│   ├── styles/         # темы
│   └── services/       # сервис ошибок
```

## Функциональность

- Ввод трёх числовых параметров (0–100) через форму
- Валидация полей через React Hook Form
- Реактивное обновление графика при добавлении данных
- Импорт данных из CSV-файла
- Удаление отдельных записей с графика
- Очистка всех данных
- Переключение светлой / тёмной темы
- Глобальный сервис ошибок с toast-уведомлениями
